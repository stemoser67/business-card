# Carte de visite

Petite carte de visite web : recto/verso (clic pour retourner), export du contact en `.vcf` et impression au format 85 × 55 mm.

## Utiliser sans rien installer

Double-clic sur `index.html` : la page s'ouvre dans le navigateur.

## Modifier ses infos

Dans `index.html`, change l'objet `person` (nom, titre, email, téléphone, lieu, site web).
Couleurs : variables en haut de `styles.css`. Logo : `images/logo.svg`.

## Avec Vite (optionnel, nécessite Node.js)

```bash
npm install
npm run dev
```

`npm run build` produit une version prête à mettre en ligne dans `dist/`.
